Labels for my home-made after shave.


# Basic Ingredients
This formula doesn't have a label.

* 50ml 75% Ethanol
* 50ml Rose Water
* 2ml Glycerin


# Glacier Ingredients
Mix 20g Menthol Crystals in 1L 96% Ethanol.

* 45ml Ethanol-Menthol mix
* 40ml Rose Water
* 20ml Willow Water
* 1.1ml Glycerin


# How to build the PDF
```
nix develop # or use DirEnv
poetry install
poetry run python aftershave/src/main.py
```
